一、复用：从位置无关到分布式与智能体

1. DARIC: A Position-Independent KV Cache Reuse System with Distribution-Aware Recomputation

  • 链接：https://arxiv.org/abs/2611.09109
  • 时间：2026-11-06
  • 方向：位置无关复用 · 重算调度 · 系统协同

摘要：agent 系统与 RAG 把上下文不断拉长，预填充成为主要开销，而跨请求复用位置无关 KV cache 需要对选定 token 子集做重算来恢复跨块交互。已有方案在算法上忽略 KV 偏差的分布特征，导致 token 选择开销高或生成质量下降；在系统上又依赖自定义执行流，难以嵌入高度优化的推理引擎。DARIC 以系统—算法协同设计：用分布感知的 token 选择策略按经验偏差模式自适应调度重计算，并以轻量架构支持独立的 KV 生成与重计算、保留引擎原有的系统级优化。多数据集与多模型实验显示，TTFT 取得 1.1×–4.5× 加速，生成质量损失可忽略。

对广域的启示：复用的收益不只取决于“能否命中”，更取决于“命中后要补多少交互”——把偏差分布当作调度信号，是位置无关缓存走向生产部署的关键一步。

2. Nebula: Distributed Position-Independent Caching for LLM Serving

  • 链接：https://arxiv.org/abs/2611.09474
  • 时间：2026-11-06
  • 方向：分布式缓存 · 位置无关复用 · 预填充调度

摘要：RAG 与 agent 的长提示由多个独立文本段拼成，预填充成为主要计算来源；分布式缓存把 KV 摊到集群以扩大总容量，位置无关缓存（PIC）则让反复出现的段能在不同前缀下复用，但现有分布式系统仍只做前缀缓存（PC），而现有 PIC 方法又缺乏集群级资源管理。Nebula 把 PIC 段当作一等公民，支持远程 PIC 复用与并行预填充：用乐观记账＋事件驱动更新维护及时可信的集群视图，用集群级幽灵命中反馈自动调节 PC 与 PIC 之间的共享容量分配，并把排队、计算与 KV 传输成本纳入统一的预填充完成时间模型以指导弹性并行与局部性感知放置。四个模型、四类真实 RAG 与 agent 负载上，中位 TTFT 平均降低 61.4%，并挽回前缀缓存漏掉的 76.1% token。

对广域的启示：分布式 KV 的下一个战场是“容量如何在 PC 与 PIC 之间分配”以及“传输成本如何进入调度决策”，这两点决定了跨节点复用能否真正兑现。

3. TwinHash: Two-Sided Object Identity Management for Time- and Energy-Efficient Agentic Workflows

  • 链接：https://arxiv.org/abs/2611.09254
  • 时间：2026-11-06
  • 方向：对象标识 · 智能体工作流 · 层级存储

摘要：agent 服务在 LLM 生成与外部工具执行之间交替，反复回到相同的推理状态，在工具输出、LLM 响应与 KV 前缀上造成大量冗余；现有服务系统只优化共享提示前缀，而仅以输入为键的朴素缓存，在相同请求可能产生不同输出时并不安全。TwinHash 为每个对象同时分配输入侧哈希键（识别重复请求）与输出侧内容指纹（校验并定位已存状态），配合按类型的复用守卫保证正确性与响应多样性；软件侧的对象标识表跨请求与轨迹管理可复用对象，硬件侧的放置表跟踪其在多级内存中的驻留，使被逐出的状态可被取回而非重算。在七个 agent 框架、五个基准上，工具输出复用率达 81%，搜索类框架的 LLM 响应复用率达 92%；从 DRAM 取回被逐出的 KV 前缀在 Qwen3-32B 上最多降低 5.6× TTFT，端到端墙钟时间最多减少 87%，任务能耗最多降低 81%。

对广域的启示：agent 负载的冗余是结构性的，缓存键必须同时覆盖“输入相同”与“输出可复用”；KV 的多级放置本质上是一个存储对象管理问题，而非单纯的张量调度问题。

4. Intent-Aware Caching for Efficient LLM Serving

  • 链接：https://arxiv.org/abs/2611.09715
  • 时间：2026-11-06
  • 方向：前缀缓存 · 淘汰策略 · 意图预测

摘要：前缀缓存复用上一轮对话的 KV 状态以省掉重复预填充，但能否命中取决于对话是否继续、下一轮何时到来，高命中率难以达成。对真实负载的分析显示，用户意图是有用信号：不同意图的续聊概率与轮间延迟明显不同。Intent-Aware Caching（IAC）按意图对请求分类，从近期服务日志中学习轻量复用统计，并据此引导一种受 oracle 启发的在线淘汰策略。在 WildChat 与 ShareChat 上，缓存命中率达 34.6%，高于此前的学习方法（18.8%）与传统 LRU（12.2%），平均服务延迟最多降低 46.1%。

对广域的启示：KV 淘汰正在从“按访问时间”转向“按行为预测”；把业务语义（意图）引入缓存管理，可能比改进缓存数据结构更划算。

二、压缩：离散瓶颈、低比特内核与运行时精度

5. Transformer-FSQ: Discrete Latents for Extreme KV-Cache Compression

  • 链接：https://arxiv.org/abs/2611.09598
  • 时间：2026-11-06
  • 方向：极端压缩 · 离散量化 · 融合内核

摘要：本地消费设备上的长上下文受制于随上下文线性增长的 KV cache：Qwen3-1.7B-Base 保留 200,000 条目需 21 GiB，是模型权重的 6.6 倍，而实测的压缩方法在较高压缩率下普遍失效。Transformer-FSQ 用有限标量量化瓶颈替换标准 key/value 投影，每个 token 只存打包的离散整数码、没有逐 token 量化元数据；微调只训练这些投影，消耗每原始参数 0.25 个 token。在 0.6B 到 8B 的模型上，长上下文检索（RULER）在 12× 至 97.5× 压缩率区间内均为所评估方法中最准确；配套融合 Triton 内核在 32× 时解码吞吐为原生 SDPA 的 1.01×（95% 区间 0.98–1.05），97.5× 时为 1.54×。

对广域的启示：把 KV 压缩从“事后量化”改为“结构内建离散瓶颈”，能在极端压缩率下同时拿到精度与免除元数据的解码效率——这对跨域传输尤为友好，因为码本比浮点张量更耐带宽约束。

6. FOSCAR: Accelerating Decode Attention over 2- and 4-Bit KV Caches through Affine Folding

  • 链接：https://arxiv.org/abs/2611.09722
  • 时间：2026-11-06
  • 方向：低比特缓存 · 解码注意力 · GPU 内核

摘要：解码注意力每个生成 token 都要流式读取 KV cache，把缓存打包成 2/4 bit 整数可降低访存但不自动变成延迟收益：现有 2-bit 融合内核在 H100/B200 上仅达峰值 HBM 吞吐的 31%/15% 以下，瓶颈是逐值施加 scale/offset 消耗了稀缺的指令发射带宽。FOSCAR 用仿射折叠把 scale 与 offset 作用到另一个操作数或矩阵乘输出上（按 token-wise 或 channel-wise 方案选择），把缩放操作减少最多两个数量级，同时保持反量化后的注意力输出在精确算术下不变；再用位操作高效喂给 Tensor Core，H100/B200 上每个 INT2 元素仅需 1 与 0.19 条 ALU 指令，并针对 Hopper（wgmma）与 Blackwell（tcgen05）构建 warp 特化流水线。H100 上 INT2/INT4 内核相对 FlashInfer BF16 几何平均加速 3.36×/2.83×、相对 TensorRT-LLM FP8 为 2.03×/1.71×；B200 上相对 FlashInfer BF16 为 2.67×/2.30×、相对 NVFP4 为 1.16×/1.00×。集成进 SGLang 后，长上下文服务峰值聚合吞吐相对 2-bit 与 16-bit 基线分别最多提升 170% 与 341%。

对广域的启示：低比特 KV 的收益上限由反量化开销决定；把缩放折叠到矩阵乘的另一侧，是把“省带宽”翻译成“省时间”的关键一步。

7. BitDecoding-FP4: Native FP4 KV Cache Decoding via Algorithm-System Co-Design

  • 链接：https://arxiv.org/abs/2611.09825
  • 时间：2026-11-06
  • 方向：FP4 量化 · 误差控制 · 服务吞吐

摘要：KV cache 主导长上下文服务的内存容量与带宽，FP4 微缩放格式（NVFP4、MXFP4）能在 FP4 张量核心上跑注意力，但算法量化与系统加速之间存在缺口：现有 FP4 KV 系统用朴素量化导致精度严重下降，而精度导向的 4-bit 算法依赖向量码本、查表开销拖慢解码。BitDecoding-FP4 逐源治理三类误差：双残差查询量化把查询切成两个 FP4 张量，将查询 logit 误差从 60% 降到 1%；下溢感知概率缩放避免 E4M3 scale 把长上下文概率舍入为零；离群感知键量化结合静态平滑、Hadamard 旋转与 scale 搜索压制 token-wise 缩放下的键离群值。系统侧用转置 softmax、融合概率量化与堆叠查询 MMA 在分页 KV 上消除 softmax 瓶颈。在密集与 MoE、GQA 与 MLA 模型上，NVFP4 与 BF16 KV 精度相差 0.5 分以内（MXFP4 为 1 分），并在 B300 上用 Qwen3-4B 与 Qwen3-30B-A3B 取得 2.4–3.0× 的峰值服务吞吐。

对广域的启示：原生 FP4 要在 KV 上可用，误差必须逐源拆解——查询、概率下溢与键离群值各有各的对策，单纯换格式不够。

8. AutoEMatic: Runtime-Adaptive Mixed-Precision LLM Inference via Automatic Exponent-Mantissa Refinement

  • 链接：https://arxiv.org/abs/2611.10165
  • 时间：2026-11-06
  • 方向：混合精度 · 运行时自适应 · 软硬协同

摘要：现有训练后量化在推理开始前就把精度定死，但模型所需的精度会随提示、层与推理阶段动态变化。AutoEMatic 在运行时自适应调整权重、激活与 KV cache 的精度：轻量策略在每个预填充与解码步，依据下一 token 分布的熵与该层隐藏状态更新的幅度为每层选精度，并由 AutoFP 这种从单一 NVFP4 基准格式派生 2/4/6 bit 的多尺度浮点格式支撑；实现覆盖在 NVFP4 张量核心上执行 AutoFP 的 GPU 内核，以及原生执行全部 AutoFP 格式的向量 MAC 加速器。在推理与 agent 基准上，相对 NVFP4 精度最多提升 21.7%，在多数基准上匹配组缩放 FP6，每权重 4.9 bit（NVFP4 为 4.5）；GB300 上保留约 90–98% 的 NVFP4 解码吞吐，加速器在同精度下延迟降低 1.6–2.3×、能耗降低 7–23%。

对广域的启示：KV 精度不必是全局常数；用运行时信号做分层、分阶段的决策，比静态混合精度更接近“按需付费”，也让压缩比可以随请求难度浮动。

三、存储视角与架构协同

9. The Storage View Of KV Cache: Characterizing Cache Behavior Across LLM Workloads

  • 链接：https://arxiv.org/abs/2611.10178
  • 时间：2026-11-06
  • 方向：存储管理 · 负载刻画 · 生命周期

摘要：KV cache 正从 GPU 显存扩展到主机 DRAM、SSD 与远程存储，但这些存储仍由 LRU、固定 TTL 等与负载无关的策略管理。该工作以块粒度刻画 11 条生产与公开 trace（聊天、API 服务、RAG、编码 agent、工具 agent、多谱系工作流）中的复用来源、重现时间与频率、有效生命周期和存储占用，发现 KV 状态呈两种反复出现的形态：单会话状态在会话内复用、随会话加深而增长并跨并发会话累积，可在长时间空闲后仍有用，但随会话结束失去价值；多会话状态跨会话复现、寿命超过单个会话，既含热点前缀也有大量低频长尾。trace 驱动比较显示，负载特定的重现估计可多保留最多 22% 的会话内命中并把死状态减少最多 40%；会话完成信号可消除单会话状态的空闲回收权衡；会话感知的复用分类比请求级访问计数精确 4–700 倍。

对广域的启示：KV 存储管理不需要应用专用语义——一个工作负载标识、一个会话标识、一个会话完成信号，就足以暴露大部分结构，这提示推理栈与存储栈之间需要一个小的跨层接口。

10. TailDART: Compute-Efficient Foundation Models for Financial Time-Series Forecasting

  • 链接：https://arxiv.org/abs/2611.09176
  • 时间：2026-11-06
  • 方向：分组查询注意力 · KV 带宽 · 时间序列

摘要：时间序列基础模型在高信息密度的物理系统上零样本迁移能力很强，但量化金融的低信噪比、非平稳与高昂的自回归解码延迟，使超参数化模型难以落地。TailDART 是一个 268 万参数的稠密基础模型，在轻量骨干中引入分组查询注意力（GQA），大幅削减 KV cache 的内存带宽开销，相对主流时间序列基础模型取得最高 48.1% 的推理加速，从而支持低延迟、高吞吐的流式执行。多资产、多时间分辨率的基准显示，紧凑模型在预测保真度上可媲美显著更大的基线，并在高波动区间表现出更强的误差韧性。

对广域的启示：GQA 这类注意力结构选择在非 LLM 负载上同样是 KV 带宽的直接杠杆；KV 优化的经验正在外溢到时间序列等相邻领域。

今日观察

  1. 复用从“前缀命中”走向“结构识别”：DARIC 看偏差分布、Nebula 认位置无关段、TwinHash 认对象指纹、IAC 认用户意图、Storage View 认会话生命周期——五种信号指向同一件事：KV 复用的单位正在从“字符串前缀”变成“可识别的复用单元”。
  2. 低比特压缩进入“系统兑现期”：FOSCAR、BitDecoding-FP4、Transformer-FSQ 都不再只报比特数与精度，而是直接报内核吞吐与端到端服务吞吐；省带宽与省时间之间的那层反量化开销，成了新的主战场。
  3. 分布式与层级化让 KV 变成存储对象：Nebula 把 KV 传输成本写进预填充完成时间模型，TwinHash 用放置表管理多级内存驻留，Storage View 则证明块粒度的生命周期足以指导回收——KV 管理越来越像缓存/存储系统问题，而不是注意力算子问题。
  4. 精度分配从静态走向运行时：AutoEMatic 按 token 熵与层更新幅度逐层定精度，配合“按需压缩”，说明 KV 预算未来更可能是随请求与阶段浮动的策略，而非一次性配置。
