一、传输与互联

1. SURMA: Efficient Fine-Grained Communication Offload for SuperPOD

  • 链接：https://arxiv.org/abs/2611.21274
  • 时间：2026-11-16
  • 方向：通信卸载 · 细粒度传输 · RDMA 适配

摘要：GPU SuperPOD 支撑大规模 LLM 服务，但带宽与往返时间的增长让 GPU 间通信占用越来越多的计算资源：SM 驱动的远端内存访问会把在飞数据放在共享内存或寄存器里，并争抢 SM 到 NoC 的带宽。专用引擎能释放这些资源，但必须处理细粒度传输——小到 576 B 的 KV cache 条目；而 NVIDIA 的 CopyEngine 在 7 KB 粒度下只用到不到 1% 的 NVLink 带宽。SURMA 是一个片上 Scale-Up 远端内存访问引擎，要让 RDMA 适配这一场景需克服四个障碍：门铃提交慢、每应用连接状态过多、共享连接上完成通知的队头阻塞、以及多路径传输的排序代价。它用信用式共享发送队列把提交延迟从 1.2μs 降到 400ns，并用融合的 write-with-atomic 语义在保持独立性的同时共享连接。

对广域的启示：KV 的传输粒度天然是“几百字节到几 KB”，通用网络栈在这个尺度上效率极低。为 KV 条目尺寸专门设计的通信引擎，可能是跨节点（进一步跨域）取数把物理带宽转成有效吞吐的关键一环。

2. Disaggregated LLM Inference in Space: A Communication Feasibility Study

  • 链接：https://arxiv.org/abs/2611.20893
  • 时间：2026-11-16
  • 方向：轨道数据中心 · PD/AFD 对比 · 链路约束

摘要：轨道数据中心有望支撑大规模 AI 推理，但要把前沿模型高效地服务给大量用户，可能需要多颗计算卫星通过光链路协作。分离式推理在地面数据中心已成熟，但其在轨道部署的独特约束下是否可行仍是开放问题。论文研究链路容量与卫星间距如何影响两类分离式服务：PD 分离（PDD） 每个请求迁移一次大 KV cache，Attention-FFN 分离（AFD） 则在每个 MoE 层、每个生成 token 上交换小激活。两者对距离的反应不同：PDD 主要受链路容量限制，链路足够快时可容忍上千公里的间距；AFD 则不然。

对广域的启示：这是“把 KV 传输推到极限”的思想实验，但结论对地面广域同样成立——PD 分离的可行性由单次大块传输的容量决定，AFD 则由高频小块交换的时延决定；选架构前先看网络是容量受限还是时延受限。

3. Callo: Serving Cache-Miss Requests with Speculative Decoding on Invalidated KV under Prefill-Decode Disaggregation

  • 链接：https://arxiv.org/abs/2611.18459
  • 时间：2026-11-13
  • 方向：失效缓存 · 推测解码 · PD 分离

摘要：agent 会话常有频繁的上下文编辑，这会使已缓存的 KV 失效，请求被迫等一次 re-prefill 才能开始解码。Callo 是一个分离式服务系统，把失效的 KV 用来做推测草稿以降低这段延迟，同时在 prefill 之后用精确 KV 验证草稿再提交 token。它通过把推测调度到解码资源空闲期、并在草稿大概率不被接受时抢占推测，来提高资源利用率。在两卡测试床、三个模型族的 SWE-agent 会话上，中等负载下全请求加速 1.05–1.19×（相对 vLLM），并用真实 trace 驱动的集群级仿真证明该收益可扩展。

对广域的启示：失效的 KV 不是垃圾——它仍能提供“差不多的”前缀信息用于草稿，只要最终用精确 KV 校验。跨域场景中，先到达的旧版本 KV 可以立刻开始工作，等新 KV 到了再纠正。

4. KVMARK: Fragile Watermarking for KV-Cache Integrity in Latent Multi-Agent Systems

  • 链接：https://arxiv.org/abs/2611.20454
  • 时间：2026-11-16
  • 方向：KV 水印 · 传输完整性 · 潜在通信

摘要：潜在多 agent 通信直接传输 transformer agent 之间的 KV 张量，绕过文本序列化；这既高效又准确，但通道不透明，容易遭到中间人篡改——这是现有基于文本或行为的 watermark 完全无法覆盖的攻击面，因为它们无法作用于连续内部表示。论文提出 KVMark：一个无需训练、零比特的 KV 缓存水印框架，用于验证 agent 交接的完整性。它包含四项设计：位置相关的符号模式（保证一阶统计不可见、同时保留下游注意力可用性）、按头符号模式并对齐检测（抵御头平均攻击）、三层深度感知的强度调度（让不同层的检测灵敏度均衡且保持不可见）等。

对广域的启示：KV 一旦离开本机，就同时面对窃听与篡改两类风险。零比特水印不占带宽却能做完整性校验，是跨域 KV 传输值得内置的一层保护。

二、压缩与量化

5. Rethinking KV Caching for LLM Decode: Free-Space Optical KV Regeneration for Reduction of Memory Traffic

  • 链接：https://arxiv.org/abs/2611.19279
  • 时间：2026-11-14
  • 方向：光学重生成 · 访存瓶颈 · 架构协同

摘要：长上下文解码反复读取历史 KV，使 MHA 受限于内存带宽。若改为缓存层输入激活，历史缓存存储与流量都能减半，但需要从每个缓存激活重生成 KV；在 GPU 这类数字加速器上，重生成比从 HBM 取激活慢得多，省下的流量被重生成开销吃掉，瓶颈从访存变成算力。论文提出 OptiDecode：一个光电混合的解码注意力加速器，用自由空间光学重生成历史 KV、用数字电路做注意力。投影权重常驻光学 tile，利用其跨历史 token 的复用实现高吞吐光学重生成；扩展到更大模型时还要解决权重分散到多 tile 后同一激活需要重复发送等问题。

对广域的启示：这是“别搬 KV，搬更小的东西再算回来”的硬件级版本。对跨域场景的启示是：把带宽压力换成算力，在算力富余、链路昂贵时是划算的——前提是重生成足够便宜。

6. MiSTiQ: MicroScaling Trellis Quantization for Extreme KV Cache Compression

  • 链接：https://arxiv.org/abs/2611.21216
  • 时间：2026-11-16
  • 方向：格量化 · MX 格式 · 低精度计算

摘要：更长上下文与更大并发同时推高 KV 体积与访存流量。KV 量化能降成本，近期用码本向量量化达到极低位宽，但受硬件限制：码本不能太大，且多数方法要先把缓存还原成高精度浮点再做注意力，量化带来的计算收益被抹掉。MiSTiQ 是码本向量量化器的直接替代：把格编码存储与 microscaling（MX）格式结合以支持低精度计算，用格量化 + beam search 在大的重建空间上编码 KV，从而不需要大码本；为支持 MX 计算还推导了 MX-Hash 函数来生成重建值。

对广域的启示：量化只有在接收端也能低精度消费时才真正省——否则解压回 BF16 会把收益吃回去。跨域传输应约定“压缩态一路走到注意力”。

7. NVFP4-MLA: Unified FP4 KV-Cache Storage and Attention Computation for Multi-Head Latent Attention

  • 链接：https://arxiv.org/abs/2611.18972
  • 时间：2026-11-13
  • 方向：MLA · FP4 存储与计算 · kernel 协同

摘要：长上下文推理与 agent 负载让 KV 容量与注意力计算成为前沿模型服务的主要成本。NVFP4-MLA 首次把 MLA 的 KV 存储与注意力计算同时推到 FP4：量化算法与注意力 kernel、缓存系统协同设计。选择性残差补偿只给量化敏感通道加 NVFP4 残差以保精度；二维量化块让共享 latent 缓存同时兼容两个注意力 BMM 的不同归约方向，省掉二者之间的重量化。在 DeepSeek-R1 与 Kimi-K3 上，九个基准的平均精度与 BF16 MLA 持平，MLA KV 缓存相对 BF16 压缩 3.20× 与 3.05×；在 NVIDIA Rubin GPU 上，注意力 kernel 相对 FP8 MLA 有明显加速。

对广域的启示：MLA 已是主流前沿模型的缓存形态，FP4 让 3× 字节缩减几乎无损；跨域传输若面向 DeepSeek/Kimi 类模型，FP4 应作为默认选项评估。

8. Memory-Efficient Speculative Decoding with Quantized Draft KV Cache

  • 链接：https://arxiv.org/abs/2611.20565
  • 时间：2026-11-16
  • 方向：推测解码 · 草稿缓存量化 · 精度分配

摘要：推测解码降低生成成本，但要同时存目标模型与草稿模型两份 KV。论文只量化草稿缓存，目标缓存与验证器保持 BF16，从而保证压缩不会改变目标模型的纠正规则。它先研究 K/V 之间如何分精度：朴素的逐 token 量化器让 key 显得敏感得多——12 bit 预算下 K8V4 比 K4V8 的接受率高 10.87 个百分点；但换成分组逐通道的 key 后，差距变成 -0.25 个百分点。受控实验证实只改 key 量化器就能抹平甚至反转偏好位宽切分。据此提出 K4V4（逐通道 key + 逐 token value）：六组模型对上草稿缓存降 66.20%，两份缓存合计降 23.95%，平均接受率从 57.93% 降到 57.14%（相对仅降 1.36%）。

对广域的启示：不是所有 KV 都同等重要——草稿模型的 KV 可以激进压缩，因为它只影响“提议”而非“最终裁决”。跨域时按“谁有权纠正”来分配压缩预算，是很有用的原则。

三、复用与状态管理

9. KaleidoKV: Rearranging Evidence for Efficient KV Cache Reuse in Offline RAG Inference

  • 链接：https://arxiv.org/abs/2611.19253
  • 时间：2026-11-14
  • 方向：RAG 复用 · 证据重排 · 批量规划

摘要：离线 RAG 批量问答中，相关问题常检索到重叠的证据，但前缀缓存只能复用完全相同的 token 前缀，复用程度取决于证据排列顺序。虽然所有问题与证据在执行前已知，现有重排方法却过早锁定分组决策，会错过需要多个请求协同移动才能形成的共享机会；而评估候选布局的规划成本又可能抵消推理节省，并发请求也可能在共享前缀的 KV 就绪前就重复计算。KaleidoKV 在批量层面规划证据顺序，并控制请求进入引擎的时机，同时保持每个请求的证据集合不变。

对广域的启示：重排就是压缩——把共享前缀对齐，等价于把“要传的字节”和“要算的 prefill”同时减少。跨域批量推理时，调度器应把“顺序”当作可优化的自由度。

10. Architectures and KV Replay for Depth-Recurrent Language Models

  • 链接：https://arxiv.org/abs/2611.19446
  • 时间：2026-11-14
  • 方向：深度循环 · KV 重放 · 架构协同

摘要：深度循环通过反复应用固定计算块来增加有效深度，但共享注意力参数并不共享不同循环轮次生成的 KV 状态，导致自回归解码时显存随循环深度增长。论文在统一框架内研究如何通过架构与缓存共享降低这部分成本：先研究循环混合架构（重复一组 Transformer 层，用循环 mLSTM 或 Gated DeltaNet 块替代大部分注意力层，并周期性保留 Transformer 注意力锚点）；再把循环限制在专门的循环工作区（Parcae 风格）并测试其稳定化 adapter；最后训练一个带循环 KV 重放的循环 Transformer——只让选定的循环轮次写 KV 状态，供后续轮次复用。

对广域的启示：模型架构层面的“少写 KV”能直接减少需要存储与传输的状态量；让少数轮次写入、其余复用，等价于把每层 KV 数按循环深度除以一个系数。

今日观察

  1. 传输粒度正在成为专门工程：SURMA 为 576B 的 KV 条目改造远端内存访问引擎，说明通用网络栈在小对象上效率极低——跨域取数同样要先解决“按对象计费”的问题。
  2. “重生成”与“传输”在硬件层面重新分工：OptiDecode 用光学就地重生成历史 KV，把带宽瓶颈换成算力瓶颈；这与 AnchorKV 的“传锚点、算回来”是同一思路的两个层次。
  3. 极端量化已进入 FP4 时代：NVFP4-MLA 在 MLA 上做到 3× 压缩且精度持平，MiSTiQ 用格量化绕开码本限制，草稿 KV 甚至可以用 K4V4。
  4. KV 离开本机后要同时防窃听与防篡改：KVMark 的零比特水印提供了一个不占带宽的完整性方案。

本期专题：混合注意力下的非前缀复用（9 篇）

应要求从本期起把「混合注意力下的非前缀复用」作为固定重点方向。这一族论文解的是同一个矛盾：全注意力的 KV 逐 token 可寻址，线性注意力层只暴露 per-request 循环状态，没有逐 token 抓手，所以传统的 splice（沿 token 轴拼接）+ correction（重算少量 token）在混合模型上直接失效，复用被迫退化为「只能命中存过 checkpoint 的离散前缀边界」。

T1. HYPIC: Position-Independent Caching for Hybrid-Attention LLM Serving

  • 链接：https://arxiv.org/abs/2607.01299
  • 时间：2026-07-01

摘要：小红书大模型推理团队 + 北大 + 上交。用 cached transitions 做近精确、常数时间的循环状态合成，把片段状态拼到任意前缀之后；四个混合模型五个负载上 TTFT 平均降 3.25×、QPS 提升 1.66×，距全量重算仅 1.71 分。这是本方向最值得先读的一篇。

T2. Beyond K/V Caches: Cross-Model State Handoff in Hybrid Linear-Attention LLMs

  • 链接：https://arxiv.org/abs/2611.08133
  • 时间：2026-11-05

摘要：跨模型要迁的不是一份 KV，而是 FA 的 K/V、循环状态 REC、卷积历史 Conv 三类异构状态；HST 保持卷积历史顺序、用结构化 REC 映射并以冻结目标模型的续写校准。Qwen3.5 4B→27B / 9B→27B 分别保持 89.88% / 94.11%，交接体加速 21.66× / 21.91×。

T3. Tail-Replay: Escaping the Curse of Linear Attention in Prefix Caching for Hybrid LLMs

  • 链接：https://arxiv.org/abs/2608.30310
  • 时间：2026-08-31

摘要：指出 checkpoint 把 token 级复用限制在离散边界；利用门控循环对早期输入的衰减，命中时只重放一小段近期尾部即可近似重建循环状态，从而解除边界约束。

T4. SparseX: Efficient Segment-Level KV Cache Sharing for Interleaved LLM Serving

  • 链接：https://arxiv.org/abs/2606.01751
  • 时间：2026-06-01

摘要：以连续 token 片段为复用单元（非前缀、跨请求、跨轮、跨 agent），用 Sparse-Q 索引估计需要修正的关键 token，把任意位置复用转化为只对必要 token 的稀疏 KV 重算。

T5. SinkState: On-the-Fly SVD of Recurrent States for Efficient Hybrid LLM Serving

  • 链接：https://arxiv.org/abs/2611.14246
  • 时间：2026-11-10

摘要：发现线性层 Q/K/V 集中在稳定低维子空间，循环状态实际低秩且秩随状态变化；全程以自适应低秩形式存储 + 局部 SVD，峰值内存降 2.6×、解码加速 1.58×。

T6. DASC: Decay-Aware State Compression for Hybrid Linear-Attention Serving

  • 链接：https://arxiv.org/abs/2608.30386
  • 时间：2026-08-31

摘要：从 GDN/KDA 的衰减结构推导 retention horizon，只保留长时域状态单元并打包成 ragged 检查点；KDA 状态压缩 2.63×，固定预算下 TTFT 降 42.6%、输入吞吐 +68.4%。

T7. Request-Adaptive Execution for Efficient Hybrid LLM Inference（Morph）

  • 链接：https://arxiv.org/abs/2610.37432
  • 时间：2026-10-27

摘要：为每个请求用 prefill gating 选择 Attention/SSM 布局，并以按层索引的混合感知上下文缓存，让后续层分叉时也能复用兼容层；吞吐最高 3.87×。

T8. Tandem: Serving Hybrid Linear-Attention GUI Agents on Mobile NPUs

  • 链接：https://arxiv.org/abs/2610.26660
  • 时间：2026-10-19

摘要：在相邻 prompt 开始分叉的位置保存循环状态供后续复用，短尾部生成 rollback 状态；端侧每步延迟降 30%、能耗降 33%。

T9. LatentPort: Beyond KV Cache — Cross-Model Transfer of Recurrent Memory in Hybrid LMs

  • 链接：https://arxiv.org/abs/2609.25053
  • 时间：2026-09-07

摘要：在 Qwen3.5 4B→9B 之间迁移持续混合状态且不重放目标前缀；只迁 attention KV 差距很大，加入 GDN 状态包后 NLL 降 0.747 nats/token。

这个方向为什么和跨广域强相关

把 9 篇放在一起看，有一条对广域最关键的线索：循环状态通常只有 MB 级，比整段 KV 小一到两个数量级。

  • HYPIC 的“状态合成”意味着跨域只需传片段状态，接收端常数时间拼装，不必重放整段上下文；
  • Tail-Replay 的“短尾重放”给出了另一种等价交换：不传状态，花算力在端侧重建；
  • DASC 与 SinkState 说明状态本身还能再压 2.6× 以上；
  • HST 与 LatentPort 则证明这套状态可以跨模型迁移，不必绑定同一版本。

换句话说，跨域复用的最优传输单元可能根本不是 KV，而是「压缩后的循环状态 + 少量修正信息」。 这与之前收录的 Close Enough is Nowhere Near（零训练跨模型 KV 替换不成立）形成有意思的对照： KV 不能直接换，但状态包可以。
