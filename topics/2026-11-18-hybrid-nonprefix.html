专题 · 混合注意力下的非前缀复用

为什么单列一个专题：主流开源模型（Qwen3.5、Kimi-Linear、MiniMax-M1、Ring-2.5 等）已把 75% 以上的层线性化，只保留少量全注意力层。这带来一个结构性矛盾——全注意力的 KV 是逐 token 可寻址的，线性注意力层只暴露一个 per-request 循环状态，没有逐 token 的抓手。于是业界成熟的「splice（沿 token 轴拼接）+ correction（重算少量 token 恢复跨段上下文）」在混合模型上直接失效：能复用的只剩严格前缀，而且只能在存过 checkpoint 的离散边界上命中。

本专题收录 6 篇直接解这道题的论文，覆盖系统（HYPIC/Tandem）、机制（Tail-Replay/SparseX）、状态压缩（DASC）与跨模型迁移（LatentPort）。HYPIC 是其中最具代表性的工作（小红书大模型推理团队 + 北京大学 + 上海交通大学）。

说明：摘要依据 arXiv 官方摘要与论文正文整理；具体实验设置与数字以原文为准。

一、系统路线：让 splice 在混合模型上重新成立

1. HYPIC: Position-Independent Caching for Hybrid-Attention LLM Serving

  • 链接：https://arxiv.org/abs/2607.01299
  • 时间：2026-07-01（v3: 2026-11-04）
  • 方向：位置无关缓存 · 循环状态合成 · RAG/Agent 服务

摘要：RAG 与 agent 场景的 prompt 由几十到上百个语义独立片段拼成，prefill 主导成本，而一旦未命中，尾 TTFT 能冲到数十秒。位置无关缓存（PIC）放开严格前缀约束、让每个片段只缓存一次并可拼接到任意前缀之后，其本质是两个原语：沿 token 轴的 splice 与重算少量 token 的 correction。但这两个原语都作用在逐 token KV 上，而混合模型的线性注意力层只有 per-request 循环状态，没有 per-token 抓手，于是混合模型里大多数层落在现有 PIC 能力范围之外。HYPIC 是首个为混合注意力模型提供 PIC 的服务系统，其关键贡献之一是基于 cached transitions 的近精确、常数时间状态合成：把片段状态与拼接前缀的状态组合成新状态，而不必重放整段上下文。四个混合模型、五个负载上，TTFT 平均降低 3.25×、QPS 提升 1.66×，任务质量距全量重算仅 1.71 分。

对广域的启示：这是本专题最有广域价值的一篇。“状态合成”意味着跨域只需传片段状态、不必传整段上下文，接收端用常数时间合成即可；而且片段状态（循环状态）通常只有 MB 级，比整段 KV 小一到两个数量级——跨广域复用的最优传输单元可能是循环状态而非 KV。

2. Tandem: Serving Hybrid Linear-Attention GUI Agents on Mobile NPUs

  • 链接：https://arxiv.org/abs/2610.26660
  • 时间：2026-10-19
  • 方向：端侧 NPU · 检查点策略 · GUI agent

摘要：手机 GUI agent 反复读屏并请求下一步动作，混合线性注意力模型能降内存，但复用循环状态需要在合适的输入位置有 checkpoint。agent 请求保留指令、重写近期历史，因此为聊天续写设计的 checkpoint 策略会错过真正可复用的前缀；为推测解码保留 rollback 状态还可能把 prompt 处理挤下 NPU 的矩阵单元，在短动作输出上得不偿失。Tandem 的做法是在相邻两次 prompt 开始分叉的位置保存循环状态，让后续请求复用已处理上下文；同时把大部分 prefill 留在矩阵单元，用短的逐 token 尾部生成 rollback 状态，验证 kernel 对所有权重块只读一次。llama.cpp 实现、两代骁龙实测：Snapdragon 8 Elite 上文本屏描述每步延迟降 30%、截图降 16%，文本步能耗降 33%，加载模型待机功耗从 0.76W 降到 0.22W。

对广域的启示：“在哪里存状态”应按复用模式决定——agent 的分叉点比固定间隔更合理。跨域缓存池同理：应当按工作流的分叉/汇合点布置状态快照，而不是按 token 数等距切分。

二、机制路线：重建状态而不是存状态

3. Tail-Replay: Escaping the Curse of Linear Attention in Prefix Caching for Hybrid LLMs

  • 链接：https://arxiv.org/abs/2608.30310
  • 时间：2026-08-31
  • 方向：前缀缓存 · 状态重放 · 边界约束

摘要：混合模型里全注意力的 KV 可 token 寻址，线性注意力层维护的循环状态却无法回滚到任意前缀边界。现有混合前缀缓存的做法是存循环状态检查点，于是 token 级匹配只在与已存检查点对齐的位置可用，复用被限制在一组离散边界上。Tail-Replay 的洞察是：门控循环更新会逐步衰减早期输入的贡献，因此匹配前缀的循环状态可以被“只重放该前缀的一小段近期尾部”很好地近似。命中时它用短尾重放重建线性注意力状态，从而解除离散边界的约束，实现不受限的 token 级匹配。

对广域的启示：“传 checkpoint”与“到端重放短尾”是一组可互换的代价：前者花带宽、后者花算力。跨域时可根据链路价格与 GPU 空闲率动态选边——这正是把带宽换成算力的典型场景。

4. SparseX: Efficient Segment-Level KV Cache Sharing for Interleaved LLM Serving

  • 链接：https://arxiv.org/abs/2606.01751
  • 时间：2026-06-01
  • 方向：片段级复用 · 稀疏重算 · 交错 prompt

摘要：长上下文服务中 prefill 主导 TTFT 与算力成本。vLLM/PagedAttention 的前缀缓存只复用完全相同的 prompt 前缀，但真实应用中重复内容常以非前缀、跨请求、跨轮次、跨 agent 的片段形式出现，常规缓存机制不够用。SparseX 以连续 token 片段为复用单元，利用 KV 复用与复杂 prompt 拼接下自然出现的 Sparse-Q 索引来估计哪些复用 token 对当前请求最重要，从而把任意位置复用转化为稀疏重算问题：只对必要的 token 做 Sparse-KV 重算，从而在复杂的交错复用模式下保住精度。

对广域的启示：片段级复用 + 局部修正，等价于把“整段搬运”换成“搬片段 + 端点少量重算”；跨域链路上这直接减少需要过网的数据量，重算部分留在本地。

5. LatentPort: Beyond KV Cache — Cross-Model Transfer of Recurrent Memory in Hybrid Language Models

  • 链接：https://arxiv.org/abs/2609.25053
  • 时间：2026-09-07
  • 方向：跨模型迁移 · 循环状态 · 免前缀重放

摘要：论文问的是：一个语言模型能否把自己的“活的记忆”交给另一个模型，而不需要接收方重读上下文？作者在一个架构匹配的 Qwen3.5 4B→9B 兄弟模型对上，展示了有用的持续混合状态迁移——据其所述是首次在混合语言模型之间、跨不同参数量、不重放目标前缀地迁移持续循环推理状态。只迁移注意力 KV 会留下很大差距；加上 Gated DeltaNet（GDN）持续状态包后，teacher-forcing 下的 NLL 降低 0.747 nats/token，64 篇 PG19 文档全部改善。

对广域的启示：如果记忆可以在模型之间迁移，那么“跨域迁移”不必绑定同一模型同一版本——迁移的单位从 KV 变成“状态包”。这与之前收录的 Close Enough is Nowhere Near（指出零训练跨模型 KV 替换不成立）形成有趣对照：KV 不能直接换，但状态包可能可以。

三、表示路线：把状态压小

6. DASC: Decay-Aware State Compression for Hybrid Linear-Attention Serving

  • 链接：https://arxiv.org/abs/2608.30386
  • 时间：2026-08-31
  • 方向：状态压缩 · 衰减结构 · 检查点布局

摘要：混合线性注意力模型的原地循环状态更新让缓存管理复杂化：前缀复用需要与全注意力 KV 并存的状态检查点，而把检查点全量存下会加剧内存压力、导致更多驱逐与重复 prefill。作者分析 Gated DeltaNet（GDN）与 Kimi Delta Attention（KDA）的衰减结构，发现不同头与通道保留前缀信息的时间尺度差异极大（称为 retention horizon），这意味着持久状态检查点有可观的压缩空间。DASC 从模型权重推导保留时域，选出长时域状态单元，打包成 ragged 检查点布局，并在张量并行下均衡到各 rank；复用时要么对省略单元零填充，要么用有界后缀计算刷新。Kimi-Linear 上保守配置已接近全量缓存，把 KDA 循环状态检查点压缩 2.63×；在固定状态检查点内存预算下，容量增益使平均 TTFT 降 42.6%、输入吞吐提升 68.4%；更大压缩比下后缀刷新能挽回大部分精度损失。Qwen + GDN 呈现相似趋势，说明方法可从 KDA 的通道维推广到 GDN 的头维。

对广域的启示：状态检查点本身也是可压缩对象，2.63× 意味着跨域传输的状态包还能再小一半以上；更关键的是“保留时域”给出了按重要性分配字节的物理依据——长时域单元才值得花带宽。

7. Beyond K/V Caches: Cross-Model State Handoff in Hybrid Linear-Attention LLMs

  • 链接：https://arxiv.org/abs/2611.08133
  • 时间：2026-11-05
  • 方向：跨模型交接 · 三类状态迁移 · 级联服务

摘要：生产部署常用模型级联、路由与切换来平衡成本与质量，上下文随轮次累积，每次切换都要目标模型重跑 prefill。现有方法只迁移全注意力的 K/V；而混合线性注意力模型还有循环状态（REC）与卷积历史（Conv），且二者互相纠缠——卷积扰动会改变循环层的 key/value 并影响 REC 更新，卷积历史会被覆盖、但 REC 的变化仍影响后续输出，因此更精确的 REC 重建并不必然带来更好的续写。论文提出 Hybrid State Transfer（HST）同时处理三类状态：用结构化 REC 映射、在卷积对齐时保持历史顺序，并用冻结目标模型的续写输出校准 adapter，FA cache 的映射则离线合并。五个基准上，Qwen3.5 4B→27B 与 9B→27B 的平均任务保持率为 89.88% 与 94.11%；源缓存已就绪时，16K 合成输入上的交接体加速达 21.66×/21.91×。

对广域的启示：跨域切换模型时，要迁的不是一份 KV，而是三类异构状态；而且“重建得更准”不等于“用得更好”，校准必须以下游续写为准。这是把“KV 传输”升级成“推理状态迁移”的最完整论述。

8. SinkState: On-the-Fly SVD of Recurrent States for Efficient Hybrid LLM Serving

  • 链接：https://arxiv.org/abs/2611.14246
  • 时间：2026-11-10
  • 方向：循环状态低秩化 · 在线 SVD · 访存优化

摘要：论文发现线性层的 query/key/value 集中在稳定低维子空间（称为 linear attention sink），因此每个循环状态实际上是低秩的、且秩随状态而变；但现有服务系统仍以稠密形式保存这些状态、每步解码全量读写，访存随 batch 增长并主导解码成本。SinkState 在推理全程用自适应低秩形式存储循环状态，配合缓冲更新与只作用于顶部子空间的局部 SVD，剩余分量异步在 CPU 上合并。四个混合模型（Mamba-2 与 GDN 层，4B–120B）上，循环状态峰值内存最多降 2.6×（平均 1.9×），解码最高加速 1.58×（平均 1.25×），精度保持不变。

对广域的启示：循环状态本身也高度冗余，低秩存储后可传输的体积再降一半以上；如果跨域只同步“顶部子空间 + 少量残差”，延迟和带宽都会显著改善。

9. Request-Adaptive Execution for Efficient Hybrid LLM Inference（Morph）

  • 链接：https://arxiv.org/abs/2610.37432
  • 时间：2026-10-27
  • 方向：请求自适应布局 · 混合感知缓存 · 选择性批处理

摘要：多数混合模型沿用静态设计：Attention-to-SSM 布局一旦选定，所有请求走同一套混合执行；但真实负载中不同请求对上下文信息的依赖方式不同，一套布局并不普适。Morph 在模型与运行时两侧协同：每个 block 内配对 Attention 与 SSM 层，用prefill 阶段的 gating 为每个请求选出专属布局（解码期间固定）；运行时用 selective batching 在层选择分歧时保住批处理效率，并用混合感知上下文缓存保证前缀复用仍然正确——传统上下文缓存要求匹配前缀的所有层缓存都可复用，任何一层 KV 或 SSM 缓存不兼容就整体算 miss，而混合感知缓存按层索引，即使后续层分叉也能复用兼容部分。六个数据集上质量-效率权衡优于静态混合基线，系统吞吐最高 3.87×。

对广域的启示：这是“按层复用”的明确主张——不必整个前缀一致，只要逐层缓存兼容就能复用。跨域场景中，这允许把“部分命中的前缀”也利用起来，而不是非黑即白。

横向对比：这个方向的四条技术路线

路线 代表 做法 代价 跨域适用性
状态合成 HYPIC 用 cached transitions 常数时间组合片段状态 需维护转移矩阵 ★★★ 最省带宽，片段可独立缓存
短尾重放 Tail-Replay 命中时重放近期尾部重建状态 花算力 ★★★ 可用算力换带宽
片段 + 稀疏修正 SparseX 片段级复用，Sparse-Q 选修正 token 需估计修正量 ★★☆ 减少过网数据
状态压缩 DASC 按保留时域裁剪检查点 精度换容量 ★★☆ 传输前可再压一档

四条路线并不互斥：DASC 压小 → SparseX 选片段 → Tail-Replay 或 HYPIC 在端侧合成/补算，可以串成一条完整的跨域复用流水线。

待解问题

  1. 状态合成的误差界：HYPIC 称“近精确”，Tail-Replay 是“很好近似”，但都缺跨片段数量增长时的误差分析——复用 100 个片段后还成立吗？
  2. checkpoint 的密度与代价：HiState（自适应间隔）、Tandem（分叉点）、Tail-Replay（免 checkpoint）三种策略，在 agent 负载上的系统性对比还没看到。
  3. 跨域的根本问题：循环状态通常 MB 级，比整段 KV 小一到两个数量级——是否已有专门“只同步循环状态”的跨广域工作？这是本方向最值得追的空缺。
  4. 与 MLA 的叠加：DeepSeek 类 MLA + 线性层混合模型上，非前缀复用的原语是什么？（已收录 arXiv:2611.12062 在翻译层做过一部分）
  5. 正确性保证：在混合模型上做非前缀复用，是否可能改变模型输出分布？有没有像 Does Accuracy Equal Evidence 那样针对"推理链"的评估？
