一、传输与跨区域

1. Towards Efficient Large Language Model Serving: A Survey on System-Aware KV Cache Optimization

  • 链接：https://arxiv.org/abs/2607.08057
  • 时间：2026-07-09
  • 方向：系统综述 · 时间/空间/结构三维度

摘要：这篇综述把“系统感知的 KV 基础设施”（sKis）拆成三个维度：执行与调度（时间）、放置与迁移（空间）、表示与保留（结构）。它不从单个算法出发，而是从系统行为看各类工作如何互相配合，并分析了跨行为的协同设计亲和性（例如调度策略会改变缓存放置的价值，表示压缩会改变迁移成本）以及行为与目标（时延、吞吐、成本）的对应关系。对跨广域场景来说，这篇的价值在于提供了一张“问题地图”：你做的压缩、复用、迁移、调度分别落在哪一格，彼此如何互相抵消或放大。

对广域的启示：跨域方案很少是单点优化，时间（调度）—空间（放置/迁移）—结构（表示/保留）必须一起设计；这张三维地图可以直接用来定位自己方案的盲区。

2. Differentially Private KV-Cache Transmission for Split LLM Inference

  • 链接：https://zenodo.org/records/19365928 ｜ DOI: 10.5281/zenodo.19365928
  • 时间：2026-04-01（Zenodo 预印本）
  • 方向：Split 推理 · KV 传输 · 差分隐私

摘要：Split LLM inference 会把 KV 向量放到网络上传给下游，而 KV-cache inversion 攻击可以从截获的 KV 重建用户输入。现有防御多是启发式混淆，没有形式化保证。HeadDP 在每个头的 key/value 投影输出上注入校准的高斯噪声，提供可证明的 (ε, δ)-差分隐私；论文进一步说明为什么在 hidden state 上直接加噪会失败：最小可用隐私预算满足 ε_min ∝ √d（由香农信道容量与 Fano 不等式推出），而在 per-head 投影空间（d_h=128，对比 d=3584）注入可把 ε_min 降低 7 倍以上。在 MMLU Medical 上，Qwen2.5-7B、Llama-3-8B、Mistral-7B 在 ε=50–75 时准确率下降 ≤5 个百分点，而对比方法在同等预算下下降超过 65 个百分点（摘要口径）。

对广域的启示：KV 一旦离开可信域，就不只是“带宽/时延”问题，还是隐私边界问题；在跨机房/边缘传输前，per-head 加噪是比“加密整条链路”更细粒度、可证明的折中。

3. Multi-Region Cloud-Native LLM Inference and Dynamic KV-Cache Routing

  • 链接：https://zenodo.org/records/23513189 ｜ DOI: 10.5281/zenodo.23513189
  • 时间：2026-10-20（Zenodo 预印本 / 生产案例研究）
  • 方向：多区域 K8s · prefix-aware 路由 · 三层内存

摘要：跨多区域云服务 LLM 时，无状态的 round-robin / least-connections 负载均衡会把相同的 system prompt、多轮历史和共享检索上下文在不同 GPU 节点上反复重算。论文提出面向多区域 Kubernetes 的 prefix-aware KV 路由 + PD 分离架构：在全局边缘入口放一个一致性哈希 radix tree 目录，后端配 GPU HBM、host DDR5、NVMe-over-Fabrics 三层内存。基于三区域、64 张 H100、70B 模型、72 小时生产 trace 的案例评估：动态前缀树路由把全局 KV 命中率从 6.4% 提升到 82.3%，中位 TTFT 从 420ms 降到 135ms（-67.9%），p99 TTFT 从 1890ms 降到 410ms（-78.3%），单 GPU 可持续吞吐提升 210.7%。论文还讨论了 AZ 分区故障恢复、共享前缀缓存的跨租户侧信道风险与 FinOps 成本。

对广域的启示：这是“全局目录 + 本地命中”的工程样板：广域复用要先把“哪个 region 有哪个前缀”做成可路由的目录，再让请求就近命中；同时要提前考虑共享缓存带来的侧信道与故障切换。

二、调度与流媒体复用

4. General Non-Clairvoyant KV-Cache Scheduling via Regime-Aware Routing

  • 链接：https://arxiv.org/abs/2607.09248
  • 时间：2026-07-10
  • 方向：非盲调度 · 竞争比 · 内存预算

摘要：论文研究硬性 KV 内存预算下的批量推理调度：每个请求的 prompt 长度已知，但响应长度未知，内存占用由固定 prompt 部分加上随解码增长的响应部分组成；每一轮调度器要选一个可行 batch，驱逐请求就会丢掉已累积的 KV、浪费之前的计算。目标是在不知道真实响应长度的情况下，逼近“全知”最优调度。作者给出首个对任意 prompt 长度、任意响应长度都成立的常数竞争比算法：不依赖单一通用策略，而是用 regime-aware 路由框架，让不同子调度器处理不同的内存增长几何，再由元调度器在它们之间时间共享内存预算，并随着作业行为逐渐显露动态路由。该框架还把常数竞争比保证扩展到 makespan 与在线到达下的总完成时间。

对广域的启示：跨域调度常面对“请求会跑多久”未知的问题；按内存增长形态分而治之、再动态路由，比拍一个固定驱逐阈值更有理论保障。

5. HERMES: KV Cache as Hierarchical Memory for Efficient Streaming Video Understanding

  • 链接：https://arxiv.org/abs/2601.14724
  • 时间：2026-01-21
  • 方向：流式视频 · 分层 KV 记忆 · 训练免费

摘要：流式视频理解要求同时保持稳定理解、实时响应和低显存，而现有 MLLM 很难兼顾。HERMES 通过注意力机制分析，把 KV cache 当作分层记忆：不同粒度封装视频信息，推理时复用一份紧凑 KV，从而在资源受限下做流式理解；查询到来时不需要任何额外计算，因此能保证连续视频交互的实时性。相比此前 SOTA，TTFT 快 10 倍；即使相比均匀采样减少最多 68% 的视频 token，在所有基准上仍取得更好或相当准确率，流式数据集上最高提升 11.4%。

对广域的启示：分层 KV 记忆让“历史上下文”可以只保留一份紧凑表示，查询时不再回传/重算；对跨域流式场景，这等价于把“每帧都传”变成“只同步压缩记忆”。

6. StreamMem: Query-Agnostic KV Cache Memory for Streaming Video Understanding

  • 链接：https://arxiv.org/abs/2508.15717
  • 时间：2025-08-21
  • 方向：流式视频 · 查询无关压缩 · 固定大小记忆

摘要：长视频理解中，KV cache 的存储与注意力开销随视觉上下文增长；现有视觉压缩方法要么需要先编码完整上下文再压缩，要么必须预知问题，无法用于长视频和多轮对话。StreamMem 提出查询无关的 KV 记忆：以流式方式编码新帧，用视觉 token 与通用查询 token 之间的注意力分数压缩 KV，并维持固定大小的 KV 内存，从而在内存受限的长视频场景下做 QA。在三个长视频理解与两个流式视频 QA 基准上，它取得查询无关压缩的 SOTA，并与查询感知方法有竞争力。

对广域的启示：固定大小、查询无关的记忆意味着带宽和存储可预测；对跨域流式应用，不必等用户问题到达再决定传什么，能提前把记忆压到固定预算。

三、压缩与评估

7. LookaheadKV: Fast and Accurate KV Cache Eviction by Glimpsing into the Future without Generation

  • 链接：https://arxiv.org/abs/2603.10899
  • 时间：2026-03-11
  • 方向：驱逐 · 重要性预测 · 低开销

摘要：长上下文下 KV 随输入线性增长，现有方法靠重要性分数驱逐 prompt KV；近期工作用“瞥见未来”提升驱逐质量——先让 draft 模型生成一个代理未来响应，再用它估计重要性，但 draft 生成本身带来大量 prefill 开销。LookaheadKV 保留“代理未来”的好处，却不需要显式 draft 生成：给 Transformer 层加参数高效模块，直接预测真实重要性分数，运行时开销与廉价启发式相当，准确率却优于更贵的近似方法。长上下文基准上全面优于近期强基线，并把驱逐成本最多降低 14.5 倍，显著加快 TTFT。

对广域的启示：驱逐的“判断成本”本身要算进预算；用小模块预测重要性比生成代理响应更适合在线服务，也更容易和跨域预取结合。

8. Value-Aware Stochastic KV Cache Eviction for Reasoning Models

  • 链接：https://arxiv.org/abs/2606.03928
  • 时间：2026-06-02
  • 方向：推理模型 · 值状态异常 · 随机驱逐

摘要：推理模型靠长思维链提升准确率，但长输出让 KV 成为瓶颈；驱逐方法常不如“保留全量 KV 的选择式稀疏注意力”。论文定位两个关键因素：第一，极少数 value 状态幅度异常大，驱逐它们会导致灾难性失败——模型陷入重复推理循环；第二，在驱逐中引入随机性能通过增加缓存多样性提升准确率。据此提出 VaSE：训练免费，保护大幅度 value 状态，同时让驱逐决策更分散。六个推理任务上，Qwen3 模型在 4× KV 压缩下平均准确率高于同稀疏度的 SOTA 选择式方法，比最强驱逐方法高 4% 以上；支持 FlashAttention2，并可保持静态显存占用。

对广域的启示：压缩不能只看“平均重要性”，尾部异常值决定成败；对需要跨域传输的推理负载，保护少量关键 value 比均匀压缩更稳。

9. Does Accuracy Equal Evidence? Reasoning Faithfulness under KV Cache Compression

  • 链接：https://arxiv.org/abs/2608.01631
  • 时间：2026-08-03
  • 方向：压缩评估 · 答案-证据差距

摘要：KV 压缩通常用最终答案准确率评估，隐含假设“答案对＝推理过程也保住了”。论文用固定轨迹重放协议（保持推理内容不变，只隔离压缩是否保留了可用信息）检验这个假设，覆盖 10 种 token 驱逐方法与 1 种量化方法、3 个模型、数学推理/科学 QA/临床计算/长上下文检索四类任务，测量最终准确率、答案链一致性与扰动忠实度。结果发现 answer-evidence gap：token 驱逐方法可以保持有竞争力的最终准确率，却显著削弱链式支持或扰动忠实度；而保留覆盖率的量化对照受影响小得多，说明问题更多来自“丢失了对推理轨迹部分内容的访问”，而非单纯的 KV 内存减少。

对广域的启示：跨域压缩/驱逐的质量评估不能只看准确率；证据链是否还在是更敏感的信号，尤其对审计、医疗、代码等高风险场景。

10. Understanding the Physics of Key-Value Cache Compression for LLMs through Attention Dynamics

  • 链接：https://arxiv.org/abs/2603.01426
  • 时间：2026-03-02
  • 方向：压缩机理 · 注意力路由 · 相变

摘要：论文反对“80–90% 压缩、基准几乎不掉分”式的评估，指出注意力不只是存储，还是路由：保留 KV 不等于语义上仍可访问。作者提出把 KV 压缩视为对 token 级路由的受控扰动，区分保留（retention）、可访问（accessibility）、可利用（utilization）三个概念。用多实体跟踪、消歧、共指、多跳推理等合成任务发现：中等压缩会明显退化内部表示但准确率几乎不变（冗余）；所有模型在约 90% 压缩附近出现幻觉安全悬崖，并与 Global Eviction Ratio 尖峰相关，提示语义可达性发生相变；架构差异明显——LLaMA 早共识、晚分化，Qwen 呈漏斗式后收敛，抗压性不同；除“擦除”外还存在表示刚性：过度 head 级共识会压缩路由灵活性，即使 token 还在。

对广域的启示：压缩比的“安全区”不是线性的，接近某个阈值会出现相变；跨域传输若按固定压缩比削减字节，需要留出安全余量，并按模型架构校准。

今日观察

  1. 跨区域开始有“可复制的工程配方”：全局一致性哈希 radix 目录 + 本地三层内存，命中率 6.4%→82.3%，这比单点压缩更能解释真实收益。
  2. KV 传输的安全性被正式提出：HeadDP 说明截获 KV 可反演输入，per-head 加噪能给出 (ε,δ)-DP 保证；跨域共享缓存必须考虑侧信道。
  3. 调度理论补上了“未知响应长度”这一块：常数竞争比的 regime-aware 路由，为跨域批处理提供了可证明的基线。
  4. 压缩评估正在从“准确率”转向“证据链/可达性”：answer-evidence gap 与 90% 压缩相变都说明，压缩比的安全边界需要重新定义。
